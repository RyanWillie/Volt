Surviving current graph

  • Circuit owns logical components, exact LibraryPartRef selections, nets, and intent; it contains no resolved PhysicalPart.
  • PartLibraryBundle owns immutable definitions, physical records, and content-addressed assets.
  • BoardResolution owns authoring-time resolved physical truth; CompiledBoard owns the immutable historical result.
  • PCB, BOM, CPL, routing, rendering, KiCad, fabrication, Python Board, and ProjectBundle consumers receive that resolved context explicitly.
  • ProjectResult.write invokes the native ProjectBundle schema 2 writer; there is no second artifact writer.
  • The supported CLI executes source only through check and build; inspect, diff, and export consume verified bundles.

Retained current boundaries

Current first-version owner schemas remain version 1 where that is their canonical version. ProjectBundle remains schema version 2. A version number identifies the wire contract; it is not a content-shape switch or permission for multiple readers.

External interoperability, including KiCad and manufacturing formats, remains supported. It is an adapter boundary, not Volt artifact backward compatibility.

ProjectResult.write_manufacturing_package remains the single supported writer for its native fabrication-package format. It consumes the exact current project result and CompiledBoard handoff; it is not a ProjectBundle writer, owner, resolver, or source-backed CLI alias.

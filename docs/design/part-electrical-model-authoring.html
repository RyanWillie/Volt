01

The Part owns its behavior

A component contract defines stable pins. An exact Part implements that contract and optionally owns an immutable PartElectricalModel. An occurrence selects the Part and connects its pins to Circuit nets.

The C++ kernel owns the model, units, validation, identity and saved bytes. Python supplies concise construction syntax. You use the ordinary Part interface for a resistor, capacitor, inductor or passive network.

A model parameter is the intrinsic ideal value. Existing occurrence attributes and display text retain their own meaning; they never populate or override this model.

02

Begin with a single element

Prepare the normal exact-Part fields once: pins, component contract, footprint, mappings and illustrative identity. The builder snapshots that same component without registering a Part.

builder = library.electrical_model_builder("R330", **fields)
a = builder.terminal("a", "A")
b = builder.terminal("b", "B")
builder.resistance(
    "body", a, b,
    volt.ModelParameter(volt.ohms(330), volt.Tolerance.percent(0.01)),
)
part = library.part("R330", **fields, electrical_model=builder.build())

This excerpt uses the complete fields in the runnable API example. The full sample also authors ideal C and L with capacitance and inductance.

Every parameter takes a native Quantity. ohms(330), farads(100e-9) and henries(10e-6) construct native SI values. Bare numbers are rejected at the model parameter boundary.

03

Add private nodes to compose a model

A capacitor with series resistance and inductance remains one exact Part and one Circuit occurrence. Its internal nodes belong only to the model.

x = builder.internal_node("after_esr")
y = builder.internal_node("after_esl")
builder.resistance("esr", a, x, volt.ModelParameter(volt.ohms(0.08)))
builder.inductance("esl", x, y, volt.ModelParameter(volt.henries(1e-9)))
builder.capacitance("storage", y, b,
    volt.ModelParameter(volt.farads(10e-6), volt.Tolerance.percent(0.2)))

Use a fresh builder for this composite. Each pin gets exactly one terminal; every declared node must be used. Handles from another builder reject. Keys and endpoint direction are part of exact identity.

04

Save the Part, then remove the source

Complete the local library, select its Parts with Design.instantiate, and connect their contract pins with ordinary net operations. A Project with only a design stage can write the complete artifact closure.

library_result = library.build()
Path("library.voltlib").write_bytes(library_result.bundle_bytes)
project.run().write("project.volt")

# In a fresh process, after removing the author source and original library:
bundle = volt.ProjectBundle.open("project.volt")
artifacts = bundle.graph.artifacts

The native reader verifies the vendored exact Parts, component definitions and referenced evidence before exposing the graph. The sample compares canonical Part bytes, model keys, values, tolerance state and evidence after reopening. No author module is imported.

Evidence supports a claim; it is not the parameter itself. Attach its exact bytes via evidence_assets and reference content_hash(bytes) from the parameter. Both model and canonical Voltage/Current evidence travel with a selected Part.

05

Read the limits with the model

Input or claimMeaning
R ≥ 0; C and L > 0Finite nominal values and tolerance bounds are required. Zero ohms is valid. Zero C/L, wrong dimensions and nonfinite values reject.
No toleranceUncertainty is unspecified. This differs from explicitly zero tolerance in both identity and saved bytes.
20% toleranceTolerance.percent(0.2) normalizes to absolute deviations. It does not request corner, statistical or worst-case analysis.
No modelBehavior is unknown. An unmodeled LED or IC stays unsupported; it does not become an open circuit or acquire an inferred model.
Passive modelIdeal linear R/C/L only. It does not model nonlinear behavior, temperature effects or arbitrary ICs, and does not certify the whole design as simulation-complete.
Nominal parameterAn ideal law, separate from physical ratings and canonical V/I claims. None of this sample's values or physical definitions are manufacturer guarantees.

The completed capability is durable Part definition and inspection. Analysis requests, electrical compilation and numerical solving are separate later work. Ordinary build, check and manufacturing do not run simulation.

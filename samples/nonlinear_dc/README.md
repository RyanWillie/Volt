# Idealized diode operating point

See [the native model and explicit execution contract](../../docs/nonlinear-dc.md).
`main.py` authors exact immutable Parts and logical connectivity. `run_dc.py` saves a
logical-only bundle, reopens it, and writes successful and domain-limited native reports.
The fixed-temperature illustrative model is uncalibrated and excludes ordinary rectifier
reverse operation. Every simulation is explicitly requested.

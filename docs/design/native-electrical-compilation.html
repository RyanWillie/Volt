Volt · Native simulation foundations · S2

Compilation preserves equations.
It does not produce answers.

A DC request already owns an immutable logical snapshot and its exact selected Parts. S2 expands that request into a native, inspectable graph of node potentials, oriented branch currents and primitive laws. A complete report means those equations were constructed faithfully; it does not mean a unique numerical solution exists.

One operation, one owner

report = volt.compile_electrical(request)
if report.complete:
    model = report.model
    snapshot = model.to_json()
else:
    diagnostics = report.diagnostics
    coverage = report.coverage

The C++ entry point is compile_electrical(const DcRequest&). There is no second Circuit or resolver argument that could disagree with the request. Python calls this native operation and exposes owning inspection copies; it cannot author a replacement graph or supply its own compilation semantics.

What survives expansion

RecordMeaning retained
Logical nodesAll original NetIds and explicit hierarchical PortBinding origins in each continuity group. Circuit nets are never merged.
Private and open nodesInternal nodes are occurrence-local. Each unconnected terminal has its own pin origin; unrelated open pins cannot alias.
BranchesExact Part selection, model-element or source key, ordered endpoints, original parameter, tolerance and evidence.
ConservationCurrent contributes +i at its from node and −i at its to node. Coincident endpoints cancel in KCL without deleting the branch.
ObservationsExplicit reference-node potential and resolved voltage/current probes retain the request's sign conventions.

Storage is not erased for DC

A capacitor retains q = Cv and i = dq/dt; an inductor retains φ = Li and v = dφ/dt. A later DC consumer sets the derivatives to zero, but the compiler keeps the positive C/L parameters, branches and storage origins. Likewise, zero resistance remains v = 0, never a division by zero or an epsilon resistor.

Failure remains inspectable

Missing required model coverage, required open pins and unbound required module ports block the complete model. Optional open pins remain explicit with diagnostics. Resolved shorted branches remain visible; contradictory voltage constraints on the same resolved node or node pair produce errors. Failed reports retain coverage and diagnostics, not a partial runnable graph.

Floating gauges, numerical rank, conditioning, nonunique currents and numerical results belong to S3. A complete isolated network can therefore still be unsolvable. No source, ground, open-circuit behavior or stabilization is inferred from labels, ratings or absent models.

Identity and transport

The compiled identity covers the immutable logical input, exact selected closure, complete request, compiler-contract version and ordered graph. Inspection JSON includes that identity and the original request. It is a deterministic snapshot, not a new ProjectBundle artifact or a restoration API. Source-free input comes from the existing verified ProjectBundle and saved DC request.

Ordinary builds and manufacturing never invoke compilation automatically. Compilation changes no Circuit, Part, Board or Schematic bytes and makes no manufacturing-readiness claim.

VOLT · SIMULATION S1 · CONTRACT GUIDE

A DC request is not a solve.

S1 captures exactly what you want to drive, observe and include, then checks that the request has valid references and declared Part-model coverage. It does not expand topology or calculate voltages and currents.

assessment.complete means request-local completeness only. Floating networks, hierarchy continuity, global source loops, rank and convergence are not certified.

Three owners, one direction

OwnerMeaning
Exact PartIntrinsic R/C/L model, stable terminals, internal nodes and element keys.
Logical CircuitOccurrences, selected exact Parts, pins, nets and connectivity.
DC requestReference net, independent ideal sources, observations and explicit whole-occurrence exclusions.

None of the request operations changes the Circuit or its Parts. A pin rating, ProvidedRange, CurrentCapability, net name or ground kind never creates excitation. Adding an ideal source does not silently replace a physical power supply.

Capture first; author against the snapshot

import volt

# d, supply and return_net are existing authoring objects.
input = volt.prepare_dc_input(d)
positive = input.net(supply)
negative = input.net(return_net)
request = volt.DcRequest(
    "operating-point", input, reference=negative,
    sources=[volt.DcVoltageSource(
        "drive", positive, negative,
        volt.Quantity(volt.UnitDimension.VOLTAGE, 5.0),
    )],
    probes=[
        volt.DcVoltageProbe("rail", positive, negative),
        volt.DcSourceCurrentProbe("supply-current", "drive"),
    ],
)
assessment = request.assess()
for entry in assessment.coverage:
    print(entry.occurrence.index, entry.status)
for diagnostic in assessment.diagnostics:
    print(diagnostic["code"], diagnostic["message"])

The native input owns an immutable logical snapshot and resolved exact Parts. Its identity combines canonical logical bytes and occurrence-keyed exact Part references. References from different or stale content reject; independently reopened identical content is interchangeable. Existing captured references remain valid after authoring changes, but converting a newly stale authoring handle rejects.

Participation is explicit

Every occurrence participates by default, including DNP and unplaced occurrences. An explicit exclusion changes only this request:

replacement = volt.DcOccurrenceExclusion(
    input.occurrence(physical_supply),
    volt.DcReplacedByStimulusExclusion(["drive"]),
)
# Pass exclusions=[replacement] when constructing the request.

DcNonElectricalExclusion() and DcOutsideAnalysisExclusion() are the other typed reasons. Every exclusion remains inspectable in the request and assessment. Replacement keys must name existing sources; the request does not infer the author's replacement intent.

CoverageInterpretation
SupportedThe selected, resolved Part has a model in the bounded R/C/L vocabulary.
ExcludedThe occurrence is explicitly out of scope, with the typed reason retained.
UnselectedNo exact Part was selected.
UnresolvedThe exact selected Part is unavailable to the supplied resolver.
Model-absentThe exact Part is valid but declares no electrical model.
UnsupportedReserved for a law outside this consumer. Unreachable with the current closed R/C/L model vocabulary.

Missing behavior is never interpreted as a zero or open element. Model-absent Parts remain valid for ordinary authoring and manufacturing workflows.

Reject bad structure; report incomplete intent

Native constructors reject dangling or foreign references, duplicate source/probe keys, wrong dimensions, nonfinite values, identical source endpoints and invalid probe/replacement targets. Zero and negative finite source values are valid. Voltage probes may compare a net with itself. Model-element current probes name a participating occurrence and an exact model element key.

A missing reference is an error diagnostic, not an invented ground. Unequal ideal voltage constraints on the same authored net pair are diagnosed, accounting for reversed orientation. S1 performs no global source-loop reasoning.

Save the request; reopen against verified input

from pathlib import Path

Path("request.json").write_text(request.to_json(), encoding="utf-8")
bundle = volt.ProjectBundle.open("project.volt")
reopened_input = bundle.graph.loaded_project.circuits[0].dc_input()
reopened = volt.DcRequest.from_json(
    reopened_input, Path("request.json").read_bytes()
)

The standalone current-only volt.dc-request version 1 format stores both input digests, typed local IDs, sources, probes and exclusions. It requires the exact matching input when read. Collections are canonicalized; unknown fields, duplicate JSON keys, old versions and malformed variants reject. The existing verified ProjectBundle supplies logical and exact-Part data without importing authoring source. The request is a separate file, not an embedded ProjectBundle artifact; no runtime handles or computed results are persisted.

Where this slice stops

S1: request validity and model coverage. S2: model expansion, hierarchy and topology. S3: numerical solvability and results. Ordinary build, check and manufacturing never run a solver implicitly.

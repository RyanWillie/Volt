## Design root

| Export | Purpose |
| --- | --- |
| `volt.Design` | Root handle for one kernel-owned logical circuit plus schematic and PCB projections. |

Common methods: `net`, `nets`, `R`, `C`, `CP`, `L`, `LED`, `diode`, `switch`, `crystal`, `test_point`, `connector_1x01`, `connector_1x02`, `connector_1x03`, `regulator`, `op_amp`, `define_component`, `define_module`, `instantiate`, `schematic`, `board`, `validate`, `validate_for_pcb`, `validate_bom_readiness`, `set_sourcing_snapshot`, `bom`, `bom_csv`, `to_json`, and `write`.

## Kernel exceptions

| Export | Purpose |
| --- | --- |
| `volt.VoltError` | Base class for typed kernel structural failures. |
| `volt.UnknownEntityError` | Raised when a kernel operation references an entity that is not present in the target model. |
| `volt.DuplicateNameError` | Raised when a kernel operation would violate a unique-name or unique-reference invariant. |
| `volt.CrossReferenceError` | Raised when a kernel operation crosses model, scope, or ownership boundaries. |
| `volt.InvalidArgumentError` | Raised when a kernel operation receives an invalid caller argument. |
| `volt.InvalidStateError` | Raised when a structurally valid operation is not valid for the model's current state. |

Typed kernel exceptions preserve the exact kernel message in `str(error)` and expose
`error.code` plus `error.entity`; `entity` is either `None` or a `{"kind", "index"}`
dictionary matching the kernel diagnostic entity reference.

## Native Part electrical models

Use `Library.electrical_model_builder(name, **part_fields)` to snapshot a normal exact-Part
component, then attach `builder.build()` with `Library.part(..., electrical_model=model)`.
The builder's `resistance`, `capacitance`, and `inductance` methods compose ideal passive
linear elements over terminals and private nodes. These are native values and operations;
Python does not own model validation, unit conversion, identity or serialization.

| Export | Purpose |
| --- | --- |
| `volt.PartElectricalModelBuilder` | Native append-only builder with `terminal`, `internal_node`, typed element methods and immutable `build`. |
| `volt.PartElectricalModel` | Complete immutable model for one exact component identity, with terminal, internal-node and element inspection. |
| `volt.ModelParameter` | Native nominal Quantity, optional normalized tolerance and immutable evidence hashes. |
| `volt.ResistanceElement` | Oriented ideal resistance with finite nonnegative value and bounds, including zero ohms. |
| `volt.CapacitanceElement` | Oriented ideal capacitance with finite positive value and bounds. |
| `volt.InductanceElement` | Oriented ideal inductance with finite positive value and bounds. |
| `volt.ModelTerminal` | Immutable binding of a model terminal key to a contract PinKey. |
| `volt.ModelInternalNode` | Immutable private node inaccessible to Circuit connectivity. |
| `volt.ModelTerminalKey` | Stable model-local terminal identity. |
| `volt.ModelInternalNodeKey` | Stable model-local private-node identity, distinct from terminal keys. |
| `volt.ModelElementKey` | Stable model-local element identity. |
| `volt.ModelTerminalHandle` | Builder-owned terminal handle; another builder rejects it. |
| `volt.ModelInternalNodeHandle` | Builder-owned private-node handle; another builder rejects it. |
| `volt.PinKey` | Stable logical contract pin identity. |
| `volt.Quantity` | Native finite dimensioned quantity with canonical SI value and existing unit normalization. |
| `volt.UnitDimension` | Native closed quantity-dimension enum. |
| `volt.QuantityRange` | Native optional inclusive quantity bounds. |
| `volt.Tolerance` | Native absolute or percent deviations; missing tolerance remains distinct from explicit zero. |
| `volt.ToleranceMode` | Native absolute/percent input mode. |
| `volt.ContentHash` | Validated immutable SHA-256 content identity. |
| `volt.content_hash` | Native SHA-256 construction from exact bytes, including evidence assets. |
| `volt.ohms` | Construct a native SI Resistance Quantity. |
| `volt.farads` | Construct a native SI Capacitance Quantity. |
| `volt.henries` | Construct a native SI Inductance Quantity. |
| `volt.hertz` | Construct a native SI Frequency Quantity, not a model element. |
| `volt.seconds` | Construct a native SI Time Quantity, not a model element. |

Bare numbers do not supply model parameters. Omitted models stay absent; instance values or
display strings never infer or override intrinsic Part parameters. Models are ideal laws,
separate from canonical Voltage/Current ratings and physical guarantees. An unmodeled LED or
IC remains unsupported, and defining a passive model does not certify full-design simulation.
The [runnable examples](https://github.com/RyanWillie/Volt/tree/main/samples/electrical_part_models)
demonstrate a resistor, ideal C/L, a composite C+ESR+ESL Part, and source-free bundle reopening.
